# ☕ Mapa de Cafeterías en Asunción

Este es un mapa que muestra las 5 mejores cafeterias en asuncion, paraguay, es parte de mi practica para la utilizacion de folium.

## 📌 Contenido
- `asuncion_cafes.ipynb`: Cuaderno de colab donde se procesan los datos y se genera el mapa interactivo con marcadores y ventanas emergentes (popups).
- `cafess_asuncion.txt`: Archivo de datos con información de nombres, coordenadas, calificaciones y precios de las cafeterías.

## 🛠️ Tecnologías utilizadas
- **Python**
- **Pandas**
- **Folium**
